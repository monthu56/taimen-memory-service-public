# ADR-008: Взвешивание retrieval по авторитетности и свежести источника

## Status

Proposed (2026-07-23; предложено по разбору CodeAlive Context Engine, ожидает
утверждения владельца). Часть пакета улучшений retrieval ADR-005…008 —
принимаются независимо друг от друга.

## Context

Ранжирование сейчас — косинус (вектор) + `ts_rank` (русский FTS), слитые через
RRF (`index/store.py`). В скоринг **не входят**: `origin` (vault-документ против
origin='agent' write-back, различимый по `seen_run`/свойствам), `confidence`
(параметр `write_fact` в `retrieval/query.py`) и свежесть (дата) — хотя всё это
уже хранится.

CodeAlive взвешивает эталонные (golden) источники выше прочих. У нас, по
инварианту 5, HTTP пишет только origin='agent', а доверенный оригинал — это
vault-документы; приоритет проверенного и свежего источника в цитатах логичен и
бьёт в приоритет №2 (качество цитат-источников).

## Decision

1. **Пост-множитель ранга по факторам источника**: `origin` (по умолчанию
   vault-документ выше agent write-back, настраиваемо), `confidence` узла,
   свежесть (экспоненциальный decay по дате).
2. **Точка приложения** — этап rerank (ADR-005); если реранк выключен —
   лёгкая корректировка RRF-скора в `_rrf_merge`.
3. **Веса — из конфига** (`CB_RANK_W_ORIGIN`, `CB_RANK_W_CONFIDENCE`,
   `CB_RANK_HALFLIFE_DAYS`) с консервативными дефолтами: влияние слабое, чтобы
   не задавить релевантность.
4. **Полностью аддитивно и за флагом**: меняется только порядок `sources`,
   схема ответа — нет (инвариант 2). Факторы, сдвинувшие ранг, видны в трейсе.

## Consequences

- Цитаты тяготеют к доверенному и свежему источнику — усиление приоритета №2.
- Риск задавить релевантный, но старый/агентский факт — митигируется малыми
  весами и полу-распадом; прозрачность через трейс.
- Согласуется с ADR-002 (Principal/origin) и инвариантом 5.

## Alternatives

- **Жёсткий приоритет vault над agent** — отклонено: агентские факты часто
  свежее и уместнее; жёсткое правило их теряет.
- **Фильтрация по origin вместо взвешивания** — отклонено: режет полноту
  выдачи.
- **Не взвешивать (статус-кво)** — отклонено: не использует уже хранимые
  сигналы (`confidence`, `origin`, дата), слабее по приоритету №2.
